## 目标与范围

将首页五个任务的竖向大卡片改成紧凑横向卡片，减少任务区占用的高度，并保留现有粉彩风格和全部任务操作。

- 图标、任务名称及奖励/今日次数、完成按钮横向排列；标题自然换行。
- 网格按可用宽度排列为三列、两列或一列；手机完成按钮至少 44px 高。
- 任务继续由 Notion 驱动，保留图片/emoji 图标、设备解锁、重复完成、加载/错误/空状态和完成动画。
- 仅修改任务区结构、样式、资源版本与必要说明，不改动 API 或真实学习记录。

1. 调整任务渲染结构、响应式网格及紧凑样式，补齐按钮可访问名称和聚焦样式。

3. 完成验证并记录结果，独立提交实现与本计划完成状态，推送并部署更新。

- 五个任务的标题、每次星星、今日次数、图标和按钮保持完整可见。
- 检查 1440、768、390、320px 布局，任务区无溢出；五个任务所占高度明显降低。
- 使用本地模拟数据检查长标题、图片图标、锁定/解锁、重复完成及加载/错误/空状态，避免真实 Notion 测试写入。
- 运行 `node --check src/index.js`、`node --check public/app.js`、`git diff --check`、`npm test`、`npm run check`。
- 部署后检查静态资源与 `/api/rewards`、`/api/gifts`；记录浏览器验证如有工具限制。
