# 诗文馆

- Created: 2026-10-14
- Status: planned

## Scope and decisions

Add a read-only poetry library at `/poetry` and `/poetry/`, integrated into shared navigation. Preserve the framework-free pastel design, existing authorization controls, reward behavior and Notion records. No recitation writes or star awards in this scope.

The source is Notion database `1b586019-c92c-8364-a021-018c2b927b9a`, collection `a6186019-c92c-82d4-a645-878ddfca5433`. Configure only the non-secret database ID in wrangler.toml. Reuse the deployed NOTION_TOKEN secret; never put credentials into files or logs or replace a working token without necessity.

`GET /api/poetry` paginates all active poems in ascending numeric 序号 order. Map 标题, 原文 (preserve line breaks), 学段, 年级, 板块, 背诵状态, 计划周次, 朝代, 类型, 链接 and 音频. Resolve unique 作者 relation titles once per refresh using bounded concurrency; avoid one unbounded request per poem. Do not return unrelated author properties. Unknown/missing fields must not break the library. Preserve 复习中 as a distinct status. Never hardcode collection totals or mastered totals.

Use bounded 60-second cache and in-flight request coalescing scoped by source configuration. Do not cache failed loads. Return 60-second public cache headers on successful poetry reads only. Audio files may use HTTPS URLs with short cache lifetime; avoid printing signed URLs, do not autoplay, and fetch fresh media metadata on reload. Allow only HTTP(S) source links and audio; escape all text rendered from Notion.

The page shows collection and progress statistics, combined school stage/grade/status filters, search by title/author/dynasty/body, result count, reset controls and native keyboard-accessible expandable details with original line breaks, author, dynasty, section, source link and optional native audio controls. Grade options follow textbook sequence and remain compatible with selected stage. Support loading, error/retry, empty results, narrow screens and reduced motion. Reuse shared navigation with functioning device unlock/lock behavior, without regressing other pages.

Update README.md and project AGENTS.md for the new API, configuration and page contracts. Synthetic test fixtures only; real Notion access is read-only.
